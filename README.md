# Agent Harness Lab

持续跟进和研究业界先进的 Agent Harness 框架，通过技术文章与代码实验，探索并验证其中的工程设计。

计划：研究 Pi 的 Agent Loop、会话管理、上下文压缩、扩展系统与可恢复执行的设计。

欢迎提出问题、分享想法并参与技术讨论。
