# Agent Harness Lab

Agent Harness Lab continuously follows and studies advanced agent harness frameworks from across the industry.

It shares technical articles and code experiments that explore and verify their engineering designs.

Current examples include studies of Pi's agent loop, session management, context compaction, extension system, and recoverable execution design.

Questions, ideas, and technical discussions are welcome.
